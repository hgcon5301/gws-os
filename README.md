## 🚀 Getting Started

gws-os is a Google Workspace tool for Claude Code. It helps you work with multiple email accounts, calendars, and drives from one place. It also uses a memory system to track trust, relevance, and patterns over time.

Use it if you want a learning-first setup for Google Workspace tasks on Windows.

## ✉️ Email, Calendar, and Drive

gws-os brings three core Google Workspace tools into one flow:

- **Email**: Read, sort, and track messages across accounts
- **Calendar**: Review meetings, manage plans, and keep time blocks in order
- **Drive**: Find files and connect them to the work you are doing

It is built for people who want less switching between tabs and accounts.

## 🧠 Memory and Trust System

gws-os uses CAR Protocol memory to keep track of what it learns.

It can:

- remember useful patterns
- score relevance based on your use
- track trust across accounts and items
- detect repeated work
- surface the most useful content first

This helps the app get better at showing the right email, event, or file when you need it.

## 👤 Multi-Account Support

If you use more than one Google account, gws-os can help you manage them in one place.

You can:

- switch between accounts
- view account-specific email and calendar data
- keep files tied to the right workspace
- separate personal and work use

This is useful if you handle team mail, client mail, and personal Google services from one Windows PC.
